# 🚀 Portafolio de Automatización de Catalina Londoño

Este portafolio reúne ejemplos reales de automatización que demuestran mis habilidades como **QA Analyst** con experiencia en:

- Automatización con **Serenity BDD + Screenplay**
- **Playwright** para pruebas UI modernas
- **Karate** para pruebas de APIs (próximamente)
- Procesos QA para **iSeries / AS400**
- Integración con **Azure DevOps**
- Diseño de casos de prueba, ejecución manual y automatizada
- Uso de **Cucumber, Gherkin y Java**
